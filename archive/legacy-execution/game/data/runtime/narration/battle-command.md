# Battle and command narration
Show the command picture: units identified, terrain/frontage, messengers/signals, order delay, morale/cohesion, reserves, ammunition, horse condition, fatigue, support, and named commanders at real positions. A unit stays one troop type even when several report to one commander. A subordinate command group is one reporting node; its commander remains personally targetable. Command overload appears as queueing, delay, lost synchronization, late reserves, gaps, and reliance on subordinates, not weaker soldier bodies. Use aggregate unit results at scale; wake exact detail only where it can change outcome.
