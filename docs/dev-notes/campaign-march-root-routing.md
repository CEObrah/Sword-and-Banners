# Campaign march authority boundary

This corrective change preserves one causal chain for autonomous campaign participants:

1. `campaign_march_planning` remains a read-only staff projection.
2. `campaign_subordinate_orders` is the explicit supreme-command adoption boundary that writes exact formation-scoped NPC orders after lawful campaign authority exists.
3. `campaign_march_lifecycle` registers scheduler work only from those exact executable orders.
4. `time_integration` is the single causal registration/dispatch owner for `campaign_march` hosts.
5. Physical route legs are settled only through the existing autonomous formation movement resolver.

Tang Wei-controlled formations are excluded from autonomous subordinate-order adoption and autonomous march routing. Strategic reserve commands without an exact assigned objective remain uncommitted. No campaign state migration or retroactive movement is part of this source change.
